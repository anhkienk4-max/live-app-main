Before any environment applies the SQL, owners must review the STO-02 dependency, RLS policies, grants, role mapping, migration order, backup/rollback, and authenticated role UAT. Production is not authorized by this source work.

The proposal creates metadata references only. Product images, KV, scripts, guidelines, documents, campaign schemes, and source evidence continue to live in Drive/OneDrive through STO-02.
