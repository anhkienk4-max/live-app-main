network access, published ports, host bind mounts and nonempty public schema.

routing override. No cloud credentials or cloud fixture writes are supported.

security/auth/Payroll tests, focused lint and credential-free Next build.

route columns/check expansion without claiming a complete Staging clone.

retain approved evidence/audit, and distinguish isolated SQL from the37 browser
cases. C02/C03 cannot close from isolated rehearsal alone.
